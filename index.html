實時氣象、空域及地圖資料來源

  • 氣象預報 Open-Meteo Weather Forecast API — 提供全球實時氣溫、地面風速 (10m)、高空風速 (80m)、實時陣風、降雨量、降雨機率及未來 7 日每日氣象預報數據。
  • 香港天氣警告 香港天文台 (HKO) 開放數據 API — 提供香港本地實時生效之惡劣天氣警告（如熱帶氣旋、暴雨、強烈季候風信號等）。
  • 地磁活動 美國國家海洋暨大氣總署太空天氣預報中心 (NOAA SWPC) — 提供全球實時地磁風暴指數（Kp Index），評估衛星定位（GPS/GNSS）受磁暴干擾風險。
  • 香港禁飛區圖層 香港民航處 (CAD) eSUA 電子系統空間數據 — 整合香港《小型無人機令》下之限制飛行區（No-Fly Zones）地理邊界（GeoJSON），並透過 Turf.js 進行空間坐標檢測。
  • 地圖與地理編碼 OpenStreetMap / Komoot Photon / Nominatim — 提供互動式地圖底圖圖磚、地名正向搜尋及點擊坐標反向地理編碼服務。

各國及地區航拍法例參考出處

  • 香港 香港民航處 (Civil Aviation Department, CAD) — 第 448G 章《小型無人機令》及「SUA 一站通 (eSUA)」標準操作規定。
  • 日本 日本國土交通省航空局 (JCAB) — 《航空法》無人機飛行規則及 DIPS 2.0 (Drone/UAS Information Platform System) 註冊與申請指引。
  • 台灣 台灣交通部民用航空局 (CAA) — 《民用航空法》遙控無人機專章及「遙控無人機管理資訊系統 (DroneMap)」空域規範。
  • 英國 英國民航局 (UK Civil Aviation Authority, CAA) — UK Drone and Model Aircraft Code 及 DMARES 註冊與飛行類別（A1/A2/A3）規定。
